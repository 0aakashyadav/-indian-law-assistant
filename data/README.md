# Legal data

No verified legal-document dataset is bundled yet. Do not interpret the empty source index as comprehensive coverage.

Each ingested document should record title, type, authority, jurisdiction, relevant section, publication and commencement dates when known, version/amendment status, official URL, retrieval time, content hash, language, verification status, and legal status. Preserve official source URLs. Do not bypass access controls or website restrictions; register inaccessible sources for manual review.
